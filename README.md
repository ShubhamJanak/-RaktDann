🩸 RaktDann
RaktDann is a blood donation web platform that connects people who need blood with donors quickly. Users can search for donors, register as a donor, and post emergency blood requests, all in one place.
Rakt = blood, Daan = donation.
Built as a BSc Computer Science field project: Blood Donor Awareness and Directory Management.

🌐 Live Demo : 
👉 [Open RaktDann](https://ais-pre-lqsw3tkc7od3esgacqm76g-339388458354.asia-southeast1.run.app)

✨ Features : 
-🔍 Find Blood: search donors by blood group and location
-🩸 Donate Blood: register as a donor with your details and availability
-🚨 Emergency Requests: post urgent blood needs so donors can respond fast
-📋 Donor Directory: a database-driven list of registered donors
-📱 Responsive Design: works on mobile and desktop

🛠️ Tech Stack :
- Frontend: TypeScript, JavaScript, HTML5, CSS3 / Tailwind CSS
- Database: Firebase
- Built with: Google AI Studio

🎯 Project Objectives :
- Make it easier to find blood donors in emergencies
- Spread awareness about blood donation
- Maintain a simple, searchable donor directory

⚠️ Disclaimer
RaktDann is an academic project and not a substitute for official blood bank services. In a medical emergency, contact your nearest hospital or blood bank directly.
